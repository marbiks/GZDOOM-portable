    Help

    Launch — open index.html from this folder. No server, no install, no internet.

    Game data — none is included. Choose an IWAD you own (DOOM.WAD, DOOM2.WAD, HERETIC.WAD, …), or download the free Freedoom project separately. Add PWADs, PK3s, IPK3s or ZIPs alongside it.

    Saves — captured while you play, including mid-game saves; the game keeps running. Every engine and every game keeps its own save set. They stay in this browser until you use Export.

    Mouse — Invert Y is off by default (Settings → Input); tick it for an engine whose view looks up when you move down.

    Frame rate — VSync is off by default, so nothing is held to the monitor refresh. Uncapped is the smoothest and the lightest on the CPU: the engines' own limiter busy-waits, so a cap cuts GPU work but not CPU time.

    Controls — WASD + mouse. Esc releases the mouse, Alt+Enter fullscreen, ` console.

    Browsers — Chrome/Edge 137+ with WebGL2. Firefox needs the JSPI flag for the worker engines; GZDoom 4.14.2 only needs WebGL2.
