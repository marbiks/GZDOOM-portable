backups/
========

Put exported save archives here.

Recommended habit: before unplugging the USB drive, click "Export saves" in the
launcher and save the ZIP into this folder. That ZIP is what carries your
progress to another computer (and serves as a backup).

To restore: open index.html on any computer, click "Import saves", choose the
ZIP from this folder, then press Start game.

The browser cannot write into this folder automatically; the download dialog
asks you where to save. Choosing this folder keeps everything on the USB drive.
